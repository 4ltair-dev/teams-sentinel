> 🤖 **AI-Assisted Project**: Этот проект, архитектура и документация разработаны с использованием искусственного интеллекта (**Google DeepMind Antigravity** / **Gemini**).

**Teams Sentinel** — это автономный фоновый радар-ассистент для онлайн-пар и конференций (**Microsoft Teams**, **Zoom**, браузерные встречи).

Сервис в реальном времени слушает системный звук компьютера через локальную модель **Vosk**, отлавливает обращение преподавателя по имени или фамилии, мгновенно шлет тревогу в **Telegram**, записывает последующий вопрос преподавателя и генерирует готовую шпаргалку с ответом через **Gemini**.

Кроме того, Sentinel умеет автоматически ставить **«+»** и писать **«Здравствуйте!»** в чат Teams при перекличке, а также позволяет отправлять любые сообщения в чат прямо с телефона через Telegram-бота.

---

## 🚀 Основные возможности

- ⚡ **Мгновенный алерт (<0.2 сек):** Бот сразу шлет тревогу `🚨 ТЕБЯ ВЫЗВАЛИ НА ПАРЕ!`, как только прозвучало имя.
- 🎯 **Умная фильтрация триггеров:** Строгая грамматическая проверка склонений русских имен (*«альтаир»*, *«альтаиру»*, *«аскаров»* и т.д.). Исключены ложные срабатывания на похожие слова (*«альтернативный»*, *«альтернатива»*, *«альт»*).
- 🧠 **Готовая шпаргалка от Gemini Flash:** Сервис записывает вопрос преподавателя (по умолчанию 7 секунд), выделяет суть и генерирует естественный ответ на 1–2 предложения для мгновенного зачитывания в микрофон.
- 🤖 **Авто-плюс при перекличке:** Если 3–4 одногруппника пишут `+` в чате пары, сервис сам мгновенно печатает и отправляет `+` от твоего имени, а в Telegram присылает отчет.
- 👋 **Авто-приветствие:** Если в начале пары 3–4 человека здороваются в чате, сервис автоматически отправляет `«Здравствуйте!»` за тебя.
- 💬 **Управление чатом Teams из Telegram:** Команда `/say <текст>` или кнопка `➕ Поставить «+» в Teams` позволяет писать в чат пары прямо с телефона.
- 🔇 **100% изоляция микрофона:** Радар слушает исключительно системный звук из наушников/динамиков (PipeWire/PulseAudio monitor) и **не открывает физический микрофон**.
- 📱 **Полный контроль в один клик:** Включение, выключение, тест звука и статус работы через удобные инлайн-кнопки в Telegram-боте.

## ⚡ Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/4ltair-dev/teams-sentinel.git
cd teams-sentinel

# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Загрузка модели Vosk

Для локального распознавания русской речи без интернета скачайте легковесную модель (~45 МБ):

```bash
python download_model.py
```

### 3. Настройка конфигурации (`.env`)

Скопируйте шаблон:
```bash
cp .env.example .env
```

Откройте `.env` и укажите свои ключи:
- `TELEGRAM_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather).
- `TELEGRAM_USER_ID` — ваш числовой Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)).
- `GEMINI_API_KEY` — бесплатный API-ключ из [Google AI Studio](https://aistudio.google.com/).
- `TRIGGER_WORDS` — ваше имя, фамилия и формы обращения (через запятую, например: `иван, иванов, ваня`).

## 🔌 Подключение Авто-плюса в Teams (1 минута)

1. Установите расширение **Tampermonkey** или **Violentmonkey** в ваш браузер (Firefox / Chrome / Edge / Яндекс).
2. Нажмите на иконку расширения ➔ **«Создать новый скрипт»**.
3. Скопируйте содержимое файла [`teams_sentinel.user.js`](teams_sentinel.user.js), вставьте в редактор и нажмите **Ctrl+S** (Сохранить).
4. Откройте встречу в веб-версии Teams. В правом нижнем углу появится индикатор:  
   `🛡️ Sentinel: В сети (+:ВКЛ, Привет:ВКЛ)`.

Теперь:
- При перекличке (когда 3–4 человека пишут `+`) скрипт сам отправит `+` от вашего имени.
- При начале пары скрипт сам отправит `«Здравствуйте!»`.
- В Telegram-боте можно написать `/say Здравствуйте, я тут!` или нажать кнопку `➕ Поставить «+» в Teams`.

## 🖥️ Создание ярлыка на рабочем столе (Linux)

Чтобы запускать радар двойным кликом:

```bash
./install_desktop.sh
```

Ярлык автоматически появится на рабочем столе и в системном меню приложений.

---

## 🏃 Запуск сервиса

```bash
# Через скрипт автоматического запуска
./start.sh

# Либо напрямую через python
.venv/bin/python main.py
```

При старте бот пришлет приветственное сообщение в Telegram с инлайн-кнопками управления:
- `🟢 Включить радар` / `🔴 Выключить радар`
- `➕ Поставить «+» в Teams` / `⚙️ Авто-плюс`
- `📊 Статус`
- `🔊 Тест звука с ПК (5с)`
